# 👜 MAISON LUMIÈRE — Handcrafted Luxury Bags E-Commerce Platform

A modern, highly interactive, and responsive luxury e-commerce web application built purely with front-end technologies. Designed with an elegant beige/cream aesthetic to provide an exclusive shopping experience for high-end fashion lovers.

---

## 📸 Preview
![Maison Lumière Preview](Screenshot.png) ---

## ✨ Key Features

- **Luxury Aesthetic & Theme:** Tailored with warm beige, nude, and golden accents for an authentic luxury brand experience.
- **Dynamic Catalog:** Displays an extensive collection of 28 unique bags (`1.jpg` through `28.jpg`).
- **Interactive Shopping Bag (Cart Drawer):** - Slide-over drawer with real-time total price calculation.
  - Dynamically add, remove, and adjust product quantities.
- **Real-Time Filtering & Search:**
  - Instant live search by bag name or category.
  - Sorting options by price (Low to High, High to Low).
- **Responsive Layout:** Perfectly tuned across mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom properties (CSS variables), Grid & Flexbox, smooth transitions, and Glassmorphism effects.
- **JavaScript (ES6+):** Pure Vanilla JS for state management, DOM manipulation, filter algorithms, and interactive cart drawers.
- **FontAwesome & Google Fonts:** Cormorant Garamond & Montserrat fonts for high-end typography.
